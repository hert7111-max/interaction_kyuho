# TOY CLUB · 3D Claw Machine

방향키로 조준하고 스페이스로 인형을 잡는 Three.js 기반 3D 인형뽑기 게임입니다. 유리 캐비닛, 금속 집게와 레일, 조명, 입체 인형, 실제로 열린 출구를 코드로 모델링했습니다.

## 실행

Node.js 24 이상:

```sh
npm install
npm run dev
```

## 조작

- `↑`: 뒤로, `↓`: 앞으로, `←` / `→`: 좌우 이동. 화면 방향 버튼을 길게 눌러도 이동합니다.
- `Space` 또는 ‘인형 잡기’: 하강 → 집게 닫기 → 상승 → 출구 이동 → 펼치기 → 원위치 복귀.
- 자동 진행 중에는 방향키·스페이스·화면 버튼을 통한 집게 조작과 기계 초기화를 차단합니다. 키 반복으로 중복 회차가 시작되지 않습니다.
- 드래그: 카메라 회전. 스크롤: 확대·축소. 입체·정면·위에서 시점을 선택할 수 있습니다. 위에서 볼 때 지붕이 열려 조준하기 쉽습니다.
- ‘새로 채우기’: 회차가 끝난 후 인형과 획득 기록을 초기화합니다.

## 모델과 동작

- 15개 인형, 6가지 형태: 짱구 느낌의 토이 캐릭터, 토끼, 곰, 공룡, 강아지, 병아리. 서로 다른 색상과 의상을 사용합니다.
- 캐릭터는 큰 둥근 사각형 머리, 별도 검은 눈썹 메시, 점 눈, 열고 닫히는 입, 짧은 원통형 팔다리, 구형 손과 짧은 검은 머리카락으로 구성합니다. 기본 캐릭터의 피부·셔츠·반바지는 `#FFD9B3`, `#E63946`, `#FFD60A`입니다.
- 인형에 정점 확장 셰이더와 뒷면 렌더링 방식의 검은 외곽선을 적용했습니다.
- 캐비닛은 PBR 재질, 환경 반사, 반투명 유리, 실제 광원과 그림자를 사용합니다. 인형은 토이 스타일입니다.
- 중심을 정확히 맞출수록 잡힐 가능성과 안정성이 높습니다. 불안정한 인형은 상승 또는 운반 도중 빠질 수 있습니다. 놓친 인형은 중력·반동으로 바닥에 돌아옵니다.
- 잡은 인형은 실제 구멍과 경사로를 거쳐 왼쪽 아래 배출 트레이로 나옵니다. 획득은 중복 집계되지 않으며 컬렉션과 횟수에 반영됩니다.
- 확률과 궤적을 결합한 게임용 물리 모델입니다. 인형 전체를 연체 역학으로 계산하는 시뮬레이터는 아닙니다.

## 검사

```sh
npm test
npm run build
```

자동 검사는 이동 범위, 대각선 속도, 모든 진행 단계의 조작 잠금, 안정/불안정 집기, 낙하, 빈 집기, 출구 배출, 획득 집계, 15개 인형 수집, 초기화, 모델 크기, 외곽선 셰이더와 출구의 기하학적 개방을 확인합니다. 실제 브라우저의 WebGL 렌더링과 시각적 품질 확인은 별도입니다.

- `src/claw-game.ts`: 렌더러와 분리된 게임 상태·물리·확률 처리
- `src/machine.ts`: 기계·집게·출구 모델
- `src/toys.ts`: 인형 모델·재질·외곽선 셰이더
- `src/main.ts`: 화면·입력·카메라·3D 렌더링·효과음
- `src/style.css`: 반응형 UI

3D 모델은 외부 모델 다운로드 없이 생성됩니다. UI 폰트는 Google Fonts를 사용하며 오프라인에서는 시스템 폰트로 대체됩니다. 기존 Site 식별자와 이전 작업의 보관용 자산은 유지합니다.
