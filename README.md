# 느릿. · 너를 보고 있어

화면 중앙의 유리 구 안에 있는 야도란이 포인터를 따라 눈을 맞추고, 클릭하면 그 지점을 바라보며 윙크하고 입을 닫았다 다시 엽니다. 얼굴 양옆을 넓히고 볼, 귀, 주둥이에 입체적인 명암을 더했습니다. 첨부 참고 이미지의 얼굴을 움직일 수 있는 SVG 레이어로 재구성했습니다.

- 눈동자는 빠르게, 얼굴과 주둥이는 조금 느리게 따라 움직여 자연스러운 시차를 만듭니다.
- 클릭 위치를 잠시 바라보며 한쪽 눈으로 윙크한 뒤 다시 포인터를 따라갑니다.
- 클릭·터치·키보드·윙크 버튼으로 아래턱이 부드럽게 올라가 입을 닫고, 잠깐 유지한 다음 다시 엽니다.
- 터치와 손가락 이동을 지원하고, 터치를 놓으면 잠시 뒤 정면으로 돌아옵니다.
- 자동 눈 깜빡임, 다시 정면 버튼, 윙크 버튼을 제공합니다.
- 키보드: 구에 Tab으로 이동, 방향키로 시선 이동, Space·Enter로 윙크, Home으로 정면 보기.
- 모바일·가로 화면과 동작 줄이기 설정을 지원합니다.

## 실행 및 검사

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Node.js 24 이상. `npm test`는 실제 이벤트 핸들러와 가상 시계로 시선 추적·보간·눈동자 범위·클릭 위치 유지·윙크 복구·연속 클릭·터치·키보드·자동 눈 깜빡임을 검사합니다. `npm run build`는 TypeScript 검사와 Vite 배포 빌드를 실행합니다.

`src/main.ts`는 SVG 얼굴과 애니메이션, `src/style.css`는 화면 스타일을 담당합니다. `.openai/hosting.json`의 기존 사이트 식별자와 접근 설정을 유지합니다. `templates/`는 보관용이며 빌드에 포함되지 않습니다.
