# City in Pieces

텍스트나 버튼 없이 도시 파노라마만 화면 전체에 표시합니다. 창문과 옥상, 겹친 건물 외벽 위로 블루·그린·화이트의 큰 단색 면을 배치했습니다. 외부 이미지나 런타임 라이브러리 없이 Canvas 2D로 도시를 그립니다.

- 화면 어디든 클릭·터치하면 화면 안의 무작위 건물이 분리됩니다.
- 건물을 나눈 조각이 공중으로 벌어지고, 창문 무늬가 사라지며 단색 입체 블록으로 변합니다.
- 변환 결과는 유지됩니다. 반복 클릭하면 다른 건물이 변하고, 모두 변한 뒤에도 다시 무작위 건물을 분리할 수 있습니다.
- 세로 화면에서도 스카이라인이 화면을 채우며, 화면 크기를 바꿔도 변환한 상태를 보존합니다.
- 키보드: 캔버스에 Tab으로 이동한 뒤 Space·Enter. 동작 줄이기 설정을 지원합니다.
- 건물 외벽은 처음 한 번만 캐시하고, 분리 애니메이션이 끝나면 프레임 요청을 멈춥니다.

## 실행 및 검사

```sh
npm install
npm run dev
npm test
npm run build
```

Node.js 24 이상. `npm test`는 실제 입력 처리와 가상 시계로 랜덤 선택·분리·조각 면적·색상·반복 입력·터치·키보드·반응형·동작 줄이기를 검사합니다. `npm run build`는 TypeScript 검사와 배포 빌드를 실행합니다.

`src/main.ts`에 도시 생성, 외벽 렌더링과 분리 동작이 있습니다. `src/style.css`는 화면 전체 캔버스를 설정합니다. `.openai/hosting.json`은 기존 사이트 식별자와 배포 설정을 유지합니다. `templates/`는 보관용입니다.
