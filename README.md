# 뽁. · 작은 뽁, 가벼운 마음

검은 화면을 채운 빨간 젤리 뽁뽁이 놀이터. Vite, TypeScript, Canvas 2D로 구현했습니다.

- 클릭·터치하면 작은 표정의 뽁뽁이가 빨간 방울과 하트로 터집니다.
- 누른 채 드래그하면 지나가는 뽁뽁이가 즉시 터집니다. 빠르게 그어도 경로를 보간하며 다중 터치를 지원합니다.
- 터진 뒤 1.1~1.7초 쉬고 3.4초 동안 점차 다시 부풉니다.
- Web Audio API로 직접 합성한 세 가지 효과음을 무작위로 재생합니다. 첫 조작에서 오디오가 시작되며 소리 버튼으로 끌 수 있습니다.
- 초기화 버튼은 카운터를 비우고 모든 뽁뽁이를 다시 부풀립니다.
- 키보드: Tab으로 캔버스에 이동, 방향키로 선택, Space·Enter로 터뜨리기.
- 모바일·가로 화면, 동작 줄이기 설정, 포인터 취소를 지원합니다.

## 실행 및 검사

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Node.js 24 이상을 사용합니다. `npm test`는 실제 입력 핸들러와 가상 시계로 클릭·드래그·다중 터치·재팽창·소리 합성·음소거·키보드·화면 크기를 검사합니다. `npm run build`는 타입 검사와 배포 빌드를 실행합니다.

`src/main.ts`에 입력·오디오·그리기, `src/style.css`에 화면 스타일이 있습니다. `.openai/hosting.json`은 기존 Sites 프로젝트를 유지합니다. `templates/`는 보관용이며 빌드에 포함되지 않습니다.
