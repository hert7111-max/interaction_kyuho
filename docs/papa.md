# 파파괴 · Archive

카메라 영상 위로 성인 비율의 2D 인물이 기어오르는 인터랙션입니다. 기존의 작은 머리/몸 블록 캐릭터를 새로 그렸으며, 머리 15px·몸 120px의 약 8등신 비율에 팔다리 관절, 옷의 명암과 주름, 손가락과 신발을 넣었습니다. 다양한 피부색·헤어스타일·성별 표현·복장의 12종 인물이 8프레임 등반과 4프레임 감전/낙하 포즈를 공유합니다.

양손 검지의 무지개 레이저, 얼굴의 양 눈 발광, 감전 떨림·X-ray·연기·스파크, 중력 낙하·바닥 충돌·픽셀 피 효과·자연 소멸을 유지했습니다. 화면에는 메뉴와 조작 아이콘만 표시합니다.

```sh
npm install
npm run dev
```

`https://localhost:5173`에서 카메라 아이콘으로 시작합니다. HTTPS 또는 localhost와 카메라 권한이 필요합니다. 재생 아이콘은 카메라 없이 마우스/터치로 조준하는 체험입니다. 영상은 기기 안에서 처리합니다.

## 속도와 인원

최초 인간 버전의 속도 24–52에서 30–65로 약 25% 증가했습니다. 시작 인원은 화면 크기에 따라 6–10명(이전보다 2명 증가), 최대 인원은 24명에서 30명으로 늘렸습니다. 생성 간격도 약간 줄였으며, 급격한 떼 출현이나 돌진은 사용하지 않습니다.

## 최적화와 호환 경로

- `src/papa-sprites.ts`: 인물의 모든 포즈를 한 장의 아틀라스에 미리 그려 재사용합니다. 프레임마다 의상/인체를 다시 그리지 않습니다.
- `src/papa-renderer.ts`: 연기·레이저 광원·손끝 광원·스파크를 사전 렌더링한 텍스처로 공유합니다. 7색 빔 필라멘트와 눈 테두리 발광, 감전 효과는 유지합니다.
- `src/papa-game.ts`: 인물·입자·혈흔 객체 풀과 배열의 제자리 압축을 사용해 반복 할당과 GC를 줄입니다. 중력/낙하는 120Hz 적분을 유지합니다.
- `src/papa.ts`: 고주사율에서도 렌더링을 최대 60Hz로 제한합니다. 화면이 숨겨지면 rAF·추적·카메라 트랙을 멈추고, 돌아오면 재개합니다. 화면 회전/리사이즈 시 기존 인물을 유지합니다.
- `src/papa-tracking.ts`, `public/papa-runtime.js`: 한 번에 한 프레임만 추론합니다. 추론 시간에 맞춰 빈도를 조절하며, 모델 입력 640px·양손·얼굴 모델을 유지합니다. GPU → CPU, 워커 → DOM 실행, ImageBitmap → ImageData 경로로 대체할 수 있습니다.
- `vite.config.ts`: ES2020 대상 변환과 JS/CSS 최소화. 다른 예제는 선택할 때만 불러옵니다.
- `scripts/compress-assets.mjs`: 원본을 남긴 채 JS/CSS/SVG/WASM/모델/글꼴에 무손실 Brotli·gzip 부파일을 만듭니다. 로컬 프로덕션 서버는 Accept-Encoding/q 값을 확인해 압축본 또는 원본을 전송합니다. 모델 WASM은 지원되는 브라우저에서 gzip 다운로드/스트리밍 해제를 사용하며, 실패 시 원본으로 대체합니다.

압축 대상 약 26.52MiB에서 각 파일의 가장 작은 무손실 표현 합계가 약 12.31MiB(53.6% 감소)였습니다. 원본과 부파일을 함께 포함한 전체 배포 폴더 크기나 모든 호스팅 경로의 실제 전송량을 의미하지 않습니다.

## 검증

```sh
npm test
npm run build
```

자동 검사 23개: 인물 다양성·등반·적정 속도/인원·양손 조준·감전·연기/스파크·중력/충돌·혈흔/소멸·객체 재사용·추적 부하 조절·압축 협상과 원본 복구, 기존 Snow/WaterTouch 동작. 프로덕션 HTTP 서버의 Brotli/gzip 응답과 원본 경로, WASM gzip의 바이트 동일성도 확인했습니다.

`/scripts/papa-browser-qa.html`은 공식 Google 손/얼굴 이미지로 검증하는 개발용 페이지입니다. 기본 워커와 `?backend=pixels` 대체 경로에서 실제 양손 2개와 눈 테두리 2개가 인식됐습니다. 현재 Mac Chrome 한 대의 샘플 영상/두 빔 시나리오에서 인물 13–14명과 효과를 함께 그릴 때 게임+렌더 CPU p95는 0.4ms, rAF 간격 p95는 17.0–17.6ms였습니다. 추론 시간 자체를 0.4ms로 측정한 것이 아닙니다. `?backend=main`으로 DOM 실행 경로도 확인할 수 있습니다.

모든 OS·인앱 브라우저·장치에서 동일한 성능이나 무발열은 보장할 수 없습니다. 브라우저가 카메라/WASM/WebGL을 차단하거나 기기의 처리 능력이 부족하면 제한이 있습니다. 실제 온도·전력과 Windows/Android/iOS 및 개별 인앱 브라우저는 별도 기기 검증이 필요합니다.
