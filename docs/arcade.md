# CRT Arcade

로우폴리 방 안에서 CRT를 바라보는 1인칭 카메라 게임입니다. 책상, 창문과 저녁 도시, 두꺼운 모니터, 스피커, 머그컵, 유선 컨트롤러와 양손을 실제 3D 지오메트리로 구성했습니다. 화면에는 안내문 대신 카메라·초기화·전체 화면 아이콘과 예제 메뉴를 표시합니다.

카메라 아이콘으로 시작한 뒤 엄지를 세우고 검지를 뻗고 나머지 손가락을 접으면 손가락 총이 됩니다. 총구 방향으로 초당 12발씩 발사하며 실제 탄환이 위로 비행하는 전투기와 충돌합니다. 양손 동시 사격, 작은 조준 보조, 폭발·연기·중력 낙하와 점수를 지원합니다. 실제 눈 윤곽에는 사격 중 흰 빛과 청록색 광원이 번쩍입니다. 손의 관절 굽힘, 엄지 이동과 움직임 크기는 컨트롤러의 손가락·엄지·스틱·버튼·트리거 모션으로 이어집니다.

전투기는 8가지 실루엣과 색상의 사전 렌더링 픽셀 스프라이트입니다. 카메라와 게임은 640×480 캔버스에 함께 그리며, 볼록한 4:3 유리 표면의 셰이더가 스캔라인·색 번짐·미세한 가로 흔들림·롤링 밴드·노이즈·비네트를 적용합니다. 웹페이지의 방 전체가 아닌 모니터 안에 VHS 효과를 둡니다.

정적인 방 지오메트리는 재질별로 합쳐 호출 수를 줄이고, 전투기·탄환·효과는 상한과 객체 풀을 사용합니다. 모니터 캔버스는 30Hz, 3D/물리는 최대 60Hz, DPR은 1.35로 제한합니다. MediaPipe는 한 번에 한 프레임을 처리하고 처리 시간에 따라 추론 빈도를 조절합니다. 기존 GPU→CPU, Worker→DOM, ImageBitmap→ImageData 대체 경로를 공유합니다. 숨김 상태에서는 렌더링·추론·카메라를 일시 정지합니다.

```sh
npm test
npm run build
```

자동 검사 40개가 통과했습니다. 신규 검사는 총 자세와 열린 손 구분, 8종 기체·상승, 연사 속도·중단, 탄환 충돌·점수·폭발·연기·중력 낙하, 양손 독립 사격, 조준 반대편 오격추 방지, 장시간 객체 수 제한과 초기화를 확인합니다. 로컬에서 서버 없이 자체 완결 HTML로 구동한 3D 장면과 CRT 셰이더, 샘플 이미지·제어 입력을 시각 확인했습니다. 실제 카메라 손/눈 추적과 모바일 기기 검증은 아직 완료하지 못했습니다.

`scripts/arcade-browser-qa.ts`는 공식 Google 샘플 사진과 합성 손 입력·눈 윤곽으로 장면을 확인하는 개발용 파일입니다. 배포에는 포함하지 않습니다. 카메라 영상은 기기 내에서 처리하며 HTTPS와 카메라 권한이 필요합니다. 3D에는 WebGL2가 필요합니다.
