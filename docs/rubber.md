# 고무 인간

`/?example=rubber` 또는 상단의 **고무 인간** 메뉴에서 엽니다. 카메라 아이콘을 누르고 얼굴 위에서 엄지·검지를 모은 뒤 이동하면 그 부분의 피부가 손가락을 따라 늘어납니다. 손가락을 벌리면 살짝 반동을 보이며 약 1.5초 안팎으로 복원됩니다. 양손으로 두 지점을 동시에 잡고 서로 다른 방향으로 당길 수 있습니다. 한 손만 놓으면 그 부분만 복원됩니다.

- 얼굴·양손을 동일 프레임에서 추론하고, 화면 채움·좌우 반전·세로 화면에 맞춰 좌표를 일치시킵니다. 손바닥 크기에 비례하는 집기 간격과 히스테리시스를 사용합니다. 얼굴 바깥에서 시작한 집기는 손가락을 벌렸다 다시 집어야 합니다.
- 36개 얼굴 윤곽점을 주기적 Catmull–Rom 곡선으로 보간하고, 160방향 × 48겹의 방사형 메쉬로 만듭니다. 작은 Wendland C2 변형을 연속 적용해 긴 당김에서도 곡선의 목과 둥근 경계를 유지합니다. 삼각형 보간으로 이미 늘어난 표면의 재질 좌표를 찾습니다.
- 배경과 얼굴 표면 모두 동일한 실시간 VideoTexture를 사용합니다. 원본 카메라 좌표를 얼굴 메쉬의 UV로 갱신하므로 실제 눈·코·입과 표정이 보존됩니다. 별도 캔버스 텍스처나 캐릭터 그래픽은 사용하지 않습니다. 당기지 않을 때는 원본 영상을 직접 표시하며, 당길 때만 얼굴 메쉬와 피부색 덮개를 합성합니다.
- 양손의 이동 경로를 작은 변형으로 함께 적분하고 두 잡힌 점 사이 거리에 맞춰 영향 반경을 조정합니다. 다른 손이 잡은 점까지 끌려가는 현상을 방지합니다.
- 합성 순서는 원본 영상 → 피부색 덮개 → 늘어나는 얼굴입니다. 볼 랜드마크 205·425 주변의 패치를 평균 내어 피부색을 만들고, 얼굴과 동일한 윤곽의 덮개를 채워, 얼굴 바깥에 인공적인 피부색 테두리가 생기지 않도록 합니다. 눈·코·입 영상을 흐리는 대신 색상으로 완전히 덮습니다. 덮개 최외곽만 좁게 페더링합니다.
- 손가락 열기·손 소실·400ms 이상 추적 지연·창 포커스 이탈 시 놓습니다. 얼굴 소실 시 마스크와 잡기를 초기화합니다. 숨김 시 카메라·추론·렌더링을 일시 정지하며 종료 시 모델·워커·GPU 자원을 해제합니다.
- 기존 런타임의 모델 초기화와 GPU→CPU 처리는 재사용하고, 새 전용 런타임에서 매 추론 프레임의 전체 얼굴 랜드마크를 받습니다. Worker→DOM, ImageBitmap→ImageData 대체 경로와 추론 빈도 조절, 최대 60Hz·DPR 1.5 제한을 적용했습니다. 기존 예제의 렌더링과 기본 진입 화면은 유지했습니다.

`src/rubber.ts`는 화면·카메라 생명주기, `rubber-engine.ts`는 변형·집기·탄성, `rubber-renderer.ts`는 얼굴 메쉬·피부색 덮개·텍스처 합성, `rubber-tracking.ts`와 `public/rubber-*.js`는 추적을 담당합니다.

검증: `npm test`, `npm run build`. 신규 자동 검사는 얼굴 밖 집기 방지, 긴 당김의 재질 고정·양의 야코비안, 감쇠 반동·복원, 추적 소실 해제, 표면 피킹, 양손 동시 집기·독립 해제·변형 뒤집힘 방지와 매 프레임 얼굴·손 출력까지 확인합니다. Chrome에서 공식 샘플 사진의 얼굴 478점과 양손 2개를 실제 추론하고, 양쪽 피부가 늘어난 결과를 시각 확인했습니다. 잡힌 두 점의 GPU 픽셀은 원본 대비 채널별 최대 오차가 각각 1·0이었습니다. `scripts/rubber-browser-qa.html`은 실제 사진·MediaPipe 얼굴/양손 추론·GPU 픽셀 비교로 양손 피부 텍스처와 복원을 검사합니다. 실제 카메라의 개별 기기·조명·가림 상황은 별도 확인이 필요합니다. 카메라는 HTTPS 또는 localhost 및 권한이 필요합니다.
